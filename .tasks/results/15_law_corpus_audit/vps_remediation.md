# VPS Remediation Guide

> Step-by-step instructions to fix the production VPS that has old (buggy) ChromaDB data.

---

## Context

The production VPS at `/opt/master-of-law/` has ChromaDB data generated by the **old buggy pipeline**. This means:

- **~60 chunks** have malformed `article_number` (e.g. `"მუხლი მუხლი7.საარჩევნო..."`)
- **~20 chunks** have short-form `code_name` (e.g. `"სისხლის სამართლის კოდექსი"` instead of `"საქართველოს სისხლის სამართლის კოდექსი"`)
- **Citation service** was returning wrong code names for abbreviated references

The **code fixes** are in the repository. The VPS data needs to be updated.

---

## Prerequisites

- SSH access to the VPS as `deploy` user
- The latest code deployed (with the pipeline and citation service fixes)
- Python 3.11 available (either on VPS directly or in Docker container)

---

## Option A: Quick Fix — Patch Existing ChromaDB Data (No Re-ingestion)

This fixes the data in-place without re-running the full embedding pipeline (saves API costs).

### Step 1: Deploy Updated Code

```bash
# On the VPS
cd /opt/master-of-law
git pull origin main

# Rebuild and restart
cd backend
docker compose up -d --build

# Verify the API is healthy
curl http://localhost:8000/api/v1/health
```

This deploys the fixed `citation_service.py` immediately — all new citation extractions will use the correct ordering and abbreviation support.

### Step 2: Fix ChromaDB Metadata In-Place

Create and run this script **on the VPS** to patch the 80 affected chunks:

```bash
# SSH into the VPS
ssh -i ~/.ssh/mol_vps deploy@YOUR_VPS_IP

# Create the fix script
cat > /tmp/fix_chroma_metadata.py << 'PYTHON_SCRIPT'
"""
Patch malformed metadata in the production ChromaDB instance.
Fixes:
  1. Short-form code_name → full canonical form (20 chunks)
  2. Malformed article_number → clean "მუხლი N" format (60 chunks)
"""
import re
import chromadb

CHROMA_DIR = "/opt/master-of-law/law_corpus/data/chroma"
# If running inside Docker, the path would be:
# CHROMA_DIR = "/app/law_corpus_data/chroma"

CODE_NAME_CANONICAL = {
    "სისხლის სამართლის კოდექსი": "საქართველოს სისხლის სამართლის კოდექსი",
    "სამოქალაქო კოდექსი": "საქართველოს სამოქალაქო კოდექსი",
    "სისხლის სამართლის საპროცესო კოდექსი": "საქართველოს სისხლის სამართლის საპროცესო კოდექსი",
    "ადმინისტრაციულ სამართალდარღვევათა კოდექსი": "საქართველოს ადმინისტრაციულ სამართალდარღვევათა კოდექსი",
    "შრომის კოდექსი": "საქართველოს შრომის კოდექსი",
    "საგადასახადო კოდექსი": "საქართველოს საგადასახადო კოდექსი",
    "სამოქალაქო საპროცესო კოდექსი": "საქართველოს სამოქალაქო საპროცესო კოდექსი",
    "საარჩევნო კოდექსი": "საქართველოს საარჩევნო კოდექსი",
    "ზოგადი ადმინისტრაციული კოდექსი": "საქართველოს ზოგადი ადმინისტრაციული კოდექსი",
    "ადმინისტრაციული საპროცესო კოდექსი": "საქართველოს ადმინისტრაციული საპროცესო კოდექსი",
}

NO_PREFIX_OK = {"ნარკოტიკული საშუალებების შესახებ კანონი", "პერსონალურ მონაცემთა დაცვის შესახებ"}

def fix_code_names(collection):
    """Fix 1: Short-form code_name → canonical full form."""
    results = collection.get(limit=20000, include=["metadatas"])
    fixed = 0
    for chunk_id, meta in zip(results["ids"], results["metadatas"]):
        cn = meta.get("code_name", "")
        if cn and not cn.startswith("საქართველოს") and cn not in NO_PREFIX_OK:
            canonical = CODE_NAME_CANONICAL.get(cn)
            if canonical:
                collection.update(ids=[chunk_id], metadatas=[{**meta, "code_name": canonical}])
                fixed += 1
                if fixed <= 3:
                    print(f"  Fixed code_name: '{cn}' → '{canonical}' (chunk: {chunk_id})")
    print(f"  Total code_name fixes: {fixed}")
    return fixed

def fix_article_numbers(collection):
    """Fix 2: Malformed article_number → clean 'მუხლი N' format."""
    results = collection.get(limit=20000, include=["metadatas"])
    fixed = 0
    for chunk_id, meta in zip(results["ids"], results["metadatas"]):
        an = meta.get("article_number", "")
        # Detect malformed: "მუხლი მუხლი7.Full Title"
        if "მუხლი მუხლი" in an or (an.startswith("მუხლი") and len(an) > 50):
            num_match = re.search(r"მუხლი\s*(\d+)", an)
            if num_match:
                clean = f"მუხლი {num_match.group(1)}"
                collection.update(ids=[chunk_id], metadatas=[{**meta, "article_number": clean}])
                fixed += 1
                if fixed <= 3:
                    print(f"  Fixed article_number: '{an[:60]}...' → '{clean}' (chunk: {chunk_id})")
    print(f"  Total article_number fixes: {fixed}")
    return fixed

if __name__ == "__main__":
    print("=== ChromaDB Metadata Fix ===")
    print(f"ChromaDB path: {CHROMA_DIR}")

    client = chromadb.PersistentClient(path=CHROMA_DIR)
    collection = client.get_collection("georgian_laws")
    print(f"Collection has {collection.count()} chunks")

    cn_fixed = fix_code_names(collection)
    an_fixed = fix_article_numbers(collection)

    print(f"\n=== Done: {cn_fixed + an_fixed} total fixes applied ===")
PYTHON_SCRIPT

# Run it (use Docker exec if Python isn't installed on the host)
# Option 1: Run on host (if Python + chromadb available)
pip install chromadb
python3 /tmp/fix_chroma_metadata.py

# Option 2: Run inside the Docker container
docker compose -f /opt/master-of-law/backend/docker-compose.yml \
  exec api python3 /tmp/fix_chroma_metadata.py
```

### Step 3: Verify the Fix

## Option B: Full Re-ingestion (Clean Rebuild)

If you want a completely clean rebuild of the ChromaDB data with all pipeline fixes applied.

> ⚠️ **This requires Vertex AI API calls** for re-embedding all 15,338+ law chunks. Estimated cost: ~$2-5 for embeddings. Takes ~30-60 minutes.

### Step 1: Deploy Updated Code

```bash
cd /opt/master-of-law
git pull origin main
```

### Step 2: Re-run Law Pipeline

```bash
cd /opt/master-of-law/law_corpus

# Backup existing ChromaDB
cp -r data/chroma data/chroma_backup_$(date +%Y%m%d)

# Set up environment
export GOOGLE_APPLICATION_CREDENTIALS=/etc/master-of-law/gcp-sa-key.json
export GOOGLE_CLOUD_PROJECT=gen-lang-client-0225498420

# Re-run the main pipeline (will rebuild georgian_laws collection)
python -m pipeline.main --rebuild
```

### Step 3: Re-run Threshold Ingestion

```bash
cd /opt/master-of-law/law_corpus

# Re-ingest thresholds with canonical code names
python ingest_thresholds.py
```

### Step 4: Verify

```bash
# Run the integration tests
cd /opt/master-of-law/backend
python -m pytest tests/test_chroma_real_data.py -v --tb=short
```

## After Either Option

### Verify Citation Service

Test that the citation service correctly handles abbreviations:

```bash
curl -X POST http://localhost:8000/api/v1/consultation/ask \
  -H "Content-Type: application/json" \
  -d '{"question": "სსკ-ის 177-ე მუხლით რა სანქციაა გათვალისწინებული?"}'
```

The response should reference `"საქართველოს სისხლის სამართლის კოდექსი, მუხლი 177"` (not `"Unknown, მუხლი 177"`).

## Rollback Plan

If anything goes wrong:

```bash
# Option A rollback: ChromaDB data is persistent, no easy undo
# You'd need to re-run the old pipeline or restore from backup

# Option B rollback: Restore the backup
cd /opt/master-of-law/law_corpus
rm -rf data/chroma
cp -r data/chroma_backup_YYYYMMDD data/chroma

# Restart
cd /opt/master-of-law/backend
docker compose restart api
```
