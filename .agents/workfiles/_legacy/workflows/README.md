## How to Use

1. Copy the entire content of the workflow file
2. Paste it into a new AI conversation
3. Fill in the `[BRACKETS]` with your specific details
4. Let the AI execute the structured workflow

Each workflow follows the **Spec-Driven Development** pattern:
```
Define Success → Plan → Execute → Verify → Document
```
